DATA HANDLING & VERIFIED BOUNDARIES

Privacy: what this site actually does.

This page separates controls checked on the self-hosted gateway from provider settings that still need account-level verification. Last reviewed November 26, 2026.

Raw visitor addresses on the self-hosted gateway

The gateway must process connection addresses to serve requests and apply abuse controls. Its application-log formatters and process-output supervisor now redact IPv4 and IPv6 address literals before those diagnostics are written. Uvicorn access logging is disabled. Nginx request logging and persistent error logging are disabled on the inspected host.

Previously retained website log files were checked and address literals redacted during this review. Earlier claims that raw addresses had never been stored were incorrect and have been removed.

Scope: this verifies the inspected host’s website logging controls. It does not establish zero storage in every provider, operating-system subsystem, device, or future configuration.

What is retained for abuse control and aggregate activity?

Pseudonymous rate-limit identifiers

The local gateway derives keyed identifiers from client addresses. Its rate-limit database stores those identifiers and request times, rather than raw addresses. Entries older than the limit window are removed when new limit checks run. Pseudonymous is not the same as anonymous.

Coarse regional counters

The gateway persists regional totals and an update time. A separate, short-lived address hash can be used in memory to reduce repeated geolocation events. These counters reflect service activity and are not a reliable count of unique people. Regional hints can be imprecise.

Chat and phone services are different systems

Nemo: local inference through the NUC

Questions sent to Nemo pass through the self-hosted gateway to the configured private model host. The gateway keeps diagnostic logs and a separate size-rotated prompt audit, including redacted prompt text and pseudonymous client identifiers. Credential-pattern redaction is not a guarantee that every kind of personal information is removed. The audit logger rotates its files by size, with up to seven backups; this is not a fixed-age deletion promise.

The phone service uses a telephone provider and speech/voice services. Its diagnostic workflow can include caller metadata, transcripts, and response excerpts. It should not be described as a service that retains no personal data.

Class & Service Desk Bot: Google Cloud

The bot on chat.html runs as a separate Google Cloud service. Questions submitted there are processed by that service. Its project-level log routing, retention, and downstream configuration have not yet been verified in this review.

Cloudflare, network providers, and external assets

The public site and connected services use hosting/network infrastructure and may load third-party fonts, libraries, maps, or other resources. Those providers receive connection metadata needed to handle requests. The owner’s Cloudflare and Google Cloud account settings still need a provider-side retention check.

This site therefore does not claim that no provider ever processes or stores an address. Cloudflare log destinations and Google Cloud log routing can be configured separately. Security functionality can also set provider cookies; see Cloudflare’s cookie documentation.

What stays in your browser?

  • Previous homepage visit: one timestamp for this browser/device. That feature sends no visit timestamp to a server and does not identify you across devices.
  • Repair-shop progress: local game state when browser storage is available.
  • Interface preferences and benchmarks: features such as weather units and page-speed records may use local storage.
  • Chat display history: some interfaces remember visible messages locally; submitting a question still sends that question to the selected service.

You can remove browser-local data using the browser’s site-data controls. Storage may be unavailable in some browser modes, in which case supported features continue without persistence.
